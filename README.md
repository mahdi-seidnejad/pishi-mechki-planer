# 🐈‍⬛ Pishi Mechki Planner

A cute black-cat daily planner with green eyes, written in plain HTML, CSS and JavaScript.

- **Today Focus**: your main goal for the day, a task list, and a focus (Pomodoro) timer
- **Schedule**: an hourly timeline for the day that marks the current time
- **Report**: today's progress, done tasks, focus minutes, your streak, a 7-day chart, today's mood, and a daily note
- An animated cat whose eyes follow your mouse (click it to get a message), and a little cat that walks along the bottom of the page (click it to put it to sleep)

All data is saved in the browser (localStorage). Use the **💾 Save to file** button to download a JSON backup, and **📂 Load from file** to restore it, for example on another device. To run it, just open `index.html`.
